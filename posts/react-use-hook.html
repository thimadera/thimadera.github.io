react · did you know?

Hooks can't live inside if statements.
Except one.

use() is the official exception to the Rules of Hooks.

UserPanel.tsx
✕  useContext()
import { useContext } from 'react'; function UserPanel({ user }) { if (!user.isAdmin) return null; const perms = useContext(Perms); return <Dashboard />; }

✕ ESLint error
React Hook "useContext" is called conditionally.

✓  use()
import { use } from 'react'; function UserPanel({ user }) { if (!user.isAdmin) return null; const perms = use(Perms); return <Dashboard />; }

✓ Valid
use() only reads a resource — no state, so call order doesn't matter.
